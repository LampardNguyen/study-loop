# Đa ngôn ngữ (l10n)

- Nguồn: `lib/l10n/app_{en,vi,zh}.arb` (template là `en`, placeholder khai báo trong `@key` của file en). Sinh code bằng `flutter gen-l10n` → `lib/l10n/app_localizations*.dart`.
- Dùng: `AppLocalizations.of(context)!.key`.
- Bẫy: code gốc còn chuỗi tiếng Trung viết cứng trong UI. Đã sửa: `sentence_detail_screen.dart` ("第 x/y 句" → `sentenceProgressOf`, T14.12). Khi gặp chữ Trung trên UI, tìm bằng `grep -rn "第\|句" lib --exclude-dir=l10n`, nhưng bỏ qua log (`AppLogger.log`) và comment.
- `LearningStage.label` (enums.dart) là nhãn tiếng Trung chỉ dùng nội bộ; UI dùng `reviewStageLabel(l10n, stage)`.
